# Jan Lehaen — Portfolio

Persoonlijke portfoliowebsite, gebouwd tijdens mijn opleiding Graduaat Programmeren aan Hogeschool PXL.

🔗 **Live:** [janlehaen.be](https://janlehaen.be)

## Over dit project

Deze site toont wie ik ben, mijn vaardigheden en de projecten waar ik aan gewerkt heb. Volledig zelf gebouwd en gedeployed via GitHub Pages met een custom domein.

## Tech stack

- HTML5 & CSS3 (responsive design, media queries)
- Vanilla JavaScript
- Formspree (contactformulier)
- GitHub Pages (hosting)
